# Гостиничный комплекс «Турист»

Статический сайт для GitHub Pages. Главная — `index.html`, страницы категорий — `detail.html`, бронирование — `booking/`, документы — `legal.html`.

## TravelLine

Интеграция использует выданный отелем профиль `TL-INT-tourist37_2026-11-25`. Скрипт загружается в `<head>` всех страниц. На главной размещена форма поиска, на странице `booking/` — полная форма. Кнопки с карточек номеров передают идентификатор категории в параметре `room-type`; русский и английский языки переключаются вместе с сайтом.

| Карточка сайта | Категории TravelLine |
| --- | --- |
| Стандарт | `42421,43215` — двуспальная или две односпальные кровати |
| Улучшенный стандарт | `231745` |
| Бизнес | `42422,118129` — двуспальная или две односпальные кровати |
| Супериор | `42423` |
| Делюкс · две кровати | `221436` |
| Делюкс · кровать и диван | `221428` — в TravelLine называется «Делюкс (1 двуспальная кровать)» |

**Настройка TravelLine перед публичным тестом на GitHub Pages:** профиль формы поиска возвращает адрес `{host}/booking?...`. Проверка на опубликованном сайте подтвердила: «Найти номер» открывает `https://rreqww.github.io/booking?...` и попадает на 404, потому что страница предпросмотра находится по адресу `https://rreqww.github.io/turist-demo/booking/`. TravelLine нужно настроить отдельный путь для тестового хоста или отдельный профиль для предпросмотра. После переноса на `tourist37.ru` нужен адрес `/booking/`. Прямые кнопки сайта уже ведут на правильную страницу предпросмотра. Старый сайт эта интеграция не затрагивает.

Предложения на сайте (для групп, длительного проживания, свадеб и др.) не совпадают с названиями тарифов в `links_offer.html`. Их кнопки не привязаны к произвольным тарифам TravelLine; условия уточняются через сотрудников гостиницы.

## Проверка

Локально запускайте `python -m http.server 8000` из корня проекта. Проверены загрузка форм на десктопе и телефоне, английская версия, ссылки всех шести карточек и параметры `room-type` внутри TravelLine. Проверка не оформляла и не подтверждала бронирований.

## Материалы для финального наполнения

В ресторане «Турист» и зале «Палех» используются фотографии с прежнего сайта в `assets/legacy/`. При появлении новых материалов замените их. Цены на карточках носят справочный характер; актуальные наличие и стоимость показывает TravelLine.
