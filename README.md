# Гостиничный комплекс «Турист» — демонстрационный сайт

Статический сайт для GitHub Pages. Главная: `index.html`, страницы категорий: `detail.html?kind=rooms&id=standard`, правовая информация: `legal.html`.

## Что уже работает

- Первый экран с фирменным словом, анимацией при прокрутке и отдельными видео для широких и узких экранов.
- Разделы номеров, ресторана, конференц-залов и спецпредложений, карточки ведут на отдельные страницы.
- Адаптивная вёрстка, контакты и меню.
- Локальный шрифт AvantGardeCTT и палитра из предоставленного брендбука.

## Данные для следующего этапа

1. Код или параметры TravelLine для реального бронирования. Сейчас кнопка ведёт к телефону отдела бронирования. Фальшивой отправки брони нет.
2. Актуальные фотографии ресторана «Турист» и зала «Палех». Пока используются фотографии с [действующего сайта гостиницы](https://www.tourist37.ru/restaurants/), сохранённые в `assets/legacy/`. Перед публикацией финальной версии заменить их.
3. Окончательные описания и оснащение номеров, цены и тарифы. Сейчас цены намеренно не показаны: наличие и стоимость должны поступать из системы бронирования или утверждённого прайса.
4. Подтверждённые условия спецпредложений. Публичные страницы пока показывают общую информацию и контакт для уточнения.
5. Документы для раздела правовой информации.
6. Ссылка на профиль MAX, если нужен переход в мессенджер. Сейчас указан предоставленный номер.

Названия и общие описания сверялись с действующими страницами гостиницы: [номера](https://www.tourist37.ru/rooms/), [рестораны](https://www.tourist37.ru/restaurants/), [конференции](https://www.tourist37.ru/conference/), [спецпредложения](https://www.tourist37.ru/offers/). Контакты взяты из новых данных заказчика.

Для локального просмотра откройте `index.html` через простой HTTP сервер, например `python -m http.server 8000`. Публикация через GitHub Pages не требует сборки.
